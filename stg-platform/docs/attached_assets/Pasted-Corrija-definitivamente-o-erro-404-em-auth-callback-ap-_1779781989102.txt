FASE 2 — CRIAR ROTA REACT

Se não existir, criar:

src/pages/AuthCallback.tsx

Com comportamento:
1. Mostrar "Autenticando com Discord..."
2. Usar Supabase para recuperar a sessão
3. Se houver sessão, redirecionar para /home
4. Se não houver sessão, tentar exchangeCodeForSession se houver code na URL
5. Se falhar, redirecionar para /login
6. Nunca redirecionar para /dashboard automaticamente

Implementar algo compatível com Supabase v2:

import { useEffect } from "react";
import { useNavigate } from "react-router-dom";
import { supabase } from "@/lib/supabase";

export default function AuthCallback() {
  const navigate = useNavigate();

  useEffect(() => {
    async function handleCallback() {
      try {
        const url = new URL(window.location.href);
        const code = url.searchParams.get("code");

        if (code) {
          await supabase.auth.exchangeCodeForSession(code);
        }

        const { data } = await supabase.auth.getSession();

        if (data.session) {
          navigate("/home", { replace: true });
        } else {
          navigate("/login", { replace: true });
        }
      } catch (error) {
        console.error("Erro no callback OAuth:", error);
        navigate("/login", { replace: true });
      }
    }

    handleCallback();
  }, [navigate]);

  return (
    <div className="min-h-screen flex items-center justify-center bg-slate-950 text-white">
      <div className="text-center">
        <h1 className="text-2xl font-bold">Autenticando com Discord...</h1>
        <p className="text-slate-400 mt-2">Aguarde enquanto validamos seu acesso STG.</p>
      </div>
    </div>
  );
}

Se o projeto não usa alias @, ajustar o import para o caminho correto, por exemplo:
import { supabase } from "../lib/supabase";

FASE 4 — CONFIGURAR FALLBACK SPA

Criar server.js na raiz do frontend, ou na raiz do projeto se o frontend estiver nela.

server.js:

import express from "express";
import path from "path";
import { fileURLToPath } from "url";

const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);

const app = express();
const distPath = path.join(__dirname, "dist");

app.use(express.static(distPath));

app.get("*", (req, res) => {
  res.sendFile(path.join(distPath, "index.html"));
});

const port = process.env.PORT || 3000;

app.listen(port, "0.0.0.0", () => {
  console.log(`STG frontend rodando em http://0.0.0.0:${port}`);
});
