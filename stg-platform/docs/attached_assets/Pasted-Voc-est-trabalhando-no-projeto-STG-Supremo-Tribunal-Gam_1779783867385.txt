FASE 3 — ROTAS FASTAPI PARA DISCORD OAUTH

Criar ou ajustar em core/routes/auth.py as rotas:

GET /auth/discord/login

Essa rota deve:
1. Montar a URL oficial do Discord OAuth2.
2. Usar:
   - client_id = DISCORD_CLIENT_ID
   - redirect_uri = DISCORD_REDIRECT_URI
   - response_type = code
   - scope = identify email guilds guilds.members.read
3. Redirecionar o usuário para o Discord.

GET /auth/discord/callback

Essa rota deve:
1. Receber ?code=...
2. Trocar o code por access_token em:
   https://discord.com/api/oauth2/token
3. Buscar dados do usuário em:
   https://discord.com/api/users/@me
4. Se possível, buscar dados do membro no servidor STG:
   https://discord.com/api/users/@me/guilds/{GUILD_ID}/member
5. Identificar roles/cargos.
6. Criar ou atualizar usuário no banco, se os models existirem.
7. Gerar JWT próprio da API.
8. Redirecionar para:

FRONTEND_URL + "/auth/callback?token=JWT"

GET /auth/me

Essa rota deve:
1. Ler Authorization: Bearer TOKEN
2. Validar o JWT
3. Retornar dados do usuário:

{
  "discord_id": "...",
  "username": "...",
  "global_name": "...",
  "email": "...",
  "avatar_url": "...",
  "roles": [],
  "role_ids": [],
  "is_admin": false,
  "is_staff": false,
  "is_moderator": false,
  "can_access_dashboard": false
}

POST /auth/logout

Pode retornar:

{
  "success": true
}
