Corrija o estado de autenticação após login Supabase/Discord.

Problema atual:
O login com Discord via Supabase conclui com sucesso.
O usuário é redirecionado para /home.
Porém a navbar não muda:
- continua mostrando botão "Conectar-se"
- não mostra ícone/avatar do usuário
- não mostra menu de perfil
- não mostra opção Dashboard para usuários com permissão

Objetivo:
Após login bem-sucedido, o frontend deve reconhecer a sessão Supabase ativa e atualizar a navbar imediatamente.

Arquitetura:
- Frontend React/Vite
- Supabase Auth com Discord
- React Router
- AuthContext ou contexto equivalente já existe
- Navbar/Topbar já existe
- Dashboard só deve aparecer para admin/mod/staff

FASE 2 — CORRIGIR AUTHCONTEXT

Garantir que AuthContext:

1. Ao iniciar o app, chame:

supabase.auth.getSession()

2. Salve:
- session
- user
- loading

3. Registre listener:

supabase.auth.onAuthStateChange((event, session) => {
  setSession(session)
  setUser(session?.user ?? null)
})

4. Remova o listener no cleanup.

5. Exponha no contexto:
- user
- session
- loading
- isAuthenticated
- signOut
- refreshUser

6. Não quebrar se Supabase env estiver ausente.
7. Se VITE_REQUIRE_AUTH=false, ainda assim deve detectar sessão real se existir.

FASE 3 — CORRIGIR AUTH CALLBACK

Em src/pages/AuthCallback.tsx:

1. Mostrar loading: "Autenticando..."
2. Chamar supabase.auth.getSession()
3. Aguardar a sessão estar disponível
4. Se session existir:
   - atualizar AuthContext se necessário
   - redirecionar para /home
5. Se não existir sessão:
   - tentar aguardar brevemente
   - se falhar, redirecionar para /login com erro amigável

Não redirecionar para /dashboard automaticamente.

  import.meta.env.VITE_SUPABASE_REDIRECT_URL ||
  `${window.location.origin}/auth/callback`
